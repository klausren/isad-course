# Teaching Plans 教案与课标

This directory will contain the **sanitized (public) versions** of weekly teaching plans and the course syllabus, released progressively alongside the weekly slides.

本目录将随课件逐周发布**脱敏公开版**教案与课程标准（英文）。

## Current status 当前状态

- Weekly teaching plans (W00–W16) and the course syllabus are fully prepared in the internal course package (English). 教案（W00–W16）与课程标准已在课程内部资料中完成。
- Public release is **pending review** of the following items to avoid leaking internal assessment details: 以下内容待确认脱敏后发布，避免泄露内部考核信息：
  - Student class roster and attendance records 学生名单与考勤记录（不公开）
  - Detailed grading splits and exam answer keys 评分细则拆分与考试答案（不公开）
  - Internal course codes 校内课程编号（已替换为占位编号）

Please open an issue or contact the instructor if you need these materials for academic reference. 如需用于学术参考，欢迎提 issue 或联系授课教师。
