# ISAD 期末答辩评分标准（最终）

> **信息系统分析与设计** · Fall 2026 · 全英文授课
> 本文件只涵盖**终结性考核（W16 期末答辩）**。形成性考核（出勤、课堂参与、里程碑、平时作业）不在此文件内。

## 一、答辩考察的五项成果

| # | 考察项 | 最终包中对应的交付物 |
|---|---|---|
| ① | **用例图** Use Case Diagram | 全部 actor + 全部用例 + include/extend |
| ② | **用例描述** Use Case Specification | 2–3 份详细规约（主成功场景 + 扩展 + 前置/后置 + NFR 引用） |
| ③ | **活动图** Activity Diagram | 1 条核心业务流程（订单履约或等效），含分支 / 汇合 / 泳道 |
| ④ | **顺序图** Sequence Diagram | 2+ 张系统操作的顺序图（生命线、消息、alt/loop/opt 片段） |
| ⑤ | **界面原型** UI Prototype | 关键界面线框图 ≥ 4 屏（列表 / 详情 / 表单 / 结果或异常态），标注导航关系 |

## 三、S1 走查评分（30 分）

| 考察项 | 分值 | 优秀（A） | 合格（C） |
|---|---|---|---|
| ① 用例图 | 5 | actor 完整（含外部系统），系统边界清晰，include/extend 语义正确不过度，用例命名是动宾短语 | 用例齐全，边界大致正确，关系有用错或漏标 |
| ② 用例描述 | 6 | 主成功场景可逐步执行，扩展覆盖真实异常分支，前置/后置与 NFR 有编号对应 | 主成功场景存在，扩展不全，前后置笼统 |
| ③ 活动图 | 5 | 分支条件互斥且穷尽，汇合语义正确，泳道与 actor 对应，与规约扩展一致 | 主流程正确，个别分支条件重叠或遗漏 |
| ④ 顺序图 | 8 | 消息与规约步骤一一对应，片段语义正确（alt 守卫互斥、loop 边界明确），边界类与控制类位置合理 | 主消息链完整，片段缺失或语义含糊 |
| ⑤ 界面原型 | 6 | 界面与用例一一对应，导航覆盖主成功场景，含异常 / 空 / 加载状态，控件与领域对象一致 | 界面齐全，导航有断路，只有正常态 |

## 四、S2 逐人问答（55 分）

**抽题方式**：五项各备 2–3 个问题，每人抽 3–4 题，**可以抽到自己没做的那一项**。
**评判口径**：答得出 + 说得出理由（依据哪条原则、哪个需求编号、哪个约束）= 满分档；只答自己那块、出了范围就犹豫 = 合格档。

| 考察项 | 追问示例 |
|---|---|
| ① 用例图 | 这个 actor 为什么是 actor？把 X 移出系统边界会怎样？<br>这条 include 和 extend 怎么区分？为什么不用另一个？ |
| ② 用例描述 | 第 4 步和第 5 步之间失败会怎样？对应哪条扩展？<br>这个前置条件从哪来？对应哪条需求编号？ |
| ③ 活动图 | 这条分支条件和其他分支互斥吗？有没有第三种情况落空？<br>这里为什么需要汇合？异常路径在图上哪一段？ |
| ④ 顺序图 | 这条消息对应规约的哪一步？顺序换了会怎样？<br>这个 alt 的守卫互斥吗？为什么 X 在这里才创建？ |
| ⑤ 界面原型 | 用户在这个界面能做什么？对应哪个用例？<br>数据为空怎么显示？这个错误提示对应哪条扩展？ |

## 六、其余分项

| # | 环节 | 分值 | 优秀（A） | 合格（C） |
|---|---|---|---|---|
| S3 | 英文表达 | 10 | 术语精确，讲述清晰 | 能听懂但易出错 |
| S4 | 反思与贡献报告 | 5 | 诚实、具体、有证据支撑 | 泛泛而谈 |

**加分（≤5，总评封顶 100）**：额外设计模式 +2 · 杰出重构叙述 +2 · 杰出文档质量 +1

**扣分**：里程碑逾期（含 M5）每逾期 1 天 −10%，最多 3 天，之后 0 分 · 抄袭模型该里程碑 0 分 + 学术不端流程 · 未披露的 AI 批量生成视同抄袭（主动披露不扣分）· 非英文提交退回翻译一次（该项 −20%），二次不再受理

**等级线**：A 90–100 · B 80–89 · C 70–79 · D 60–69 · F < 60（口径统一日期 2026-11-26；分值与官方《课程考核大纲》《评分量规》一致）

**缓考 / 补考 / 争议**：缺席者凭证明在补考窗口单独答辩（问答照常逐人）· 总评 < 60 者补交一轮完整逐人问答，形成性不重做 · 组内贡献争议以 Git 记录 + 贡献日志为准；分数复议须在成绩公布 3 个工作日内书面提出
