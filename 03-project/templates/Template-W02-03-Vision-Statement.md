## Stuck?

| Symptom | Fix |
|---|---|
| It sounds like an advert | Delete every adjective. What remains is either a fact or an empty sentence. |
| Cannot name the "Unlike" | You have not studied the current process. Go and watch someone order lunch today. |
| Too long | The "that" clause is doing too much work. Keep one capability — the one you would demo first. |
| Too vague to be argued with | A good vision is falsifiable: someone should be able to say "no, that is not the problem". |
