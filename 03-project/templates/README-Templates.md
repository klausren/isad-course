## Rules for all templates

1. **English only.** A non-English deliverable is returned once for translation (−20% on that item).
2. **Delete the hints.** Any surviving `> Hint:` line or grey instruction block means the file is not finished.
3. **One source of truth.** The vision paragraph lives in `01-requirements/vision.md`; paste the same text into the charter — do not keep two versions.
4. **Diagrams** go in `docs/diagrams/`, with the `.drawio` / `.puml` source next to the exported image.
5. **A submission exists only when the tag is pushed.** See `Template-W02-05`.
