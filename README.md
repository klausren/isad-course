A complete, **English-only** open course for **Information Systems Analysis and Design** — a 16-week, 64-hour undergraduate course for international students. The course takes an object-oriented path: analysis with UML (use cases, domain models, sequence & state diagrams), design with responsibility-assignment principles (**GRASP**, **SOLID**), and finishing with the classic **GoF design patterns** and architectural patterns — all practiced on a semester-long team project, **CampusBites**.

面向国际学生的《信息系统分析与设计》全英文开源课程：16 周 / 64 学时。以面向对象为主线——UML 分析建模（用例、领域、顺序、状态图）→ 职责分配设计原则（GRASP、SOLID）→ GoF 设计模式与架构模式——并以原创贯穿项目 **CampusBites**（校园订餐配送平台）全程实践。

## 📖 Course Overview 课程简介

| Item 项目 | Detail 内容 |
|---|---|
| Course 课程 | Information Systems Analysis and Design 信息系统分析与设计 |
| Credits / Hours 学分 / 学时 | 4 credits / 64 hours (Lecture 48 + Practice 16) |
| Duration 周期 | 16 weeks, 4 hours per week (2 sessions) |
| Language 语言 | **English only 全英文**（for international students 面向国际学生） |
| Focus 定位 | OOAD: UML analysis models → GRASP & SOLID principles → GoF patterns → architecture |
| Reference 参考教材 | C. Larman, *Applying UML and Patterns* (3rd ed.); GoF; Head First Design Patterns; R. C. Martin (SOLID) |
| Project 项目 | CampusBites — a campus food ordering & delivery platform built by student teams all semester |

**Highlights 教学特色**

- 🧭 **Principles-first 先原则后模式** — Patterns are taught as consequences of GRASP/SOLID reasoning, not as recipes. 模式是原则的推论，不是菜谱。
- 🔧 **Project-driven 项目驱动** — Every week's technique maps onto a natural CampusBites feature (order lifecycle → State, payments → Strategy/Factory, tracking → Observer, toppings → Decorator, campus-card API → Adapter). 每个知识点都有项目落点。
- 🗣️ **English-only delivery 全英文** — Slides, assignments, reviews, and defense in English; English quality is part of assessment. 全英文授课与考核。
- ✍️ **Hands-on 每课练习** — Each week includes 2–3 in-class exercises with answers. 每周 2–3 个课堂练习（含答案）。
- 🎨 **Original figures 原创图表** — All diagrams are original vector drawings; the running case is original (no textbook-IP risk). 原创案例与图表，开源合规。

## 🍜 CampusBites Project 项目实践

Students work in **small teams (2–3)** throughout the semester on **CampusBites**, an original running case — a campus food ordering and delivery platform whose domain is deliberately pattern-rich:

| Course topic 课程主题 | CampusBites hook 项目落点 |
|---|---|
| State machines & State pattern | Order lifecycle: Created → Paid → Preparing → Ready → Delivered |
| Strategy | Pricing rules: happy-hour, student discount, bundle |
| Observer | Customers & couriers subscribe to order status changes |
| Adapter | Legacy campus-card API behind our `PaymentMethod` interface |
| Decorator | Meal customization: toppings, portions, add-ons |
| Facade / Factory / Builder / Command | Notification stack / payment creation / order assembly / undoable operations |

Milestones: kickoff (W2) → requirements (W5) → analysis models (W9 mid-term review) → design models (W12) → pattern catalog (W15) → final defense (W16). Assessment is **project + oral defense** (no written exam): group deliverables plus an individual defense where every team member must be able to explain any part of the work. See the [Project Guidebook](03-project/CampusBites-Project-Guidebook.md) (handed to students in Week 1 — milestones, submission rules, grading, and templates) and the [Project Brief](03-project/CampusBites-Project-Brief.md).
